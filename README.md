# BotVK — учебный MVP «СвойТон»

Минимальный VK-бот для домашнего задания по работе с API. Пользователь выбирает
бизнес-задачу, отправляет brief и получает через Polza.ai черновик контента.
Бот ничего не публикует и не отправляет автоматически.

## Что умеет бот

- написать пост;
- подготовить продающий текст;
- предложить ответ клиенту;
- придумать пять идей контента;
- переписать готовый текст;
- сохранить профиль бренда и результаты в локальной SQLite-базе;
- показать действия `Подходит`, `Ещё вариант`, `Изменить вручную`.

## Архитектура

```text
VK LongPoll
    -> bot.py / keyboards.py / states.py
    -> prompts.py
    -> polza_client.py -> Polza.ai Chat Completions
    -> storage.py / trace.py -> SQLite WAL
```

Основные технологии: Python, `vkbottle`, `httpx`, `pydantic-settings`, SQLite.
API-клиент отделён от VK-логики. Kie.ai и медиа-генерация оставлены следующим
этапом, потому что требуют отдельного асинхронного job-flow.

## Запуск в Windows PowerShell

Из папки `BotVK`:

```powershell
& .venv\Scripts\Activate.ps1
Copy-Item .env.example .env
notepad .env
```

Заполни в `.env`:

```text
VK_BOT_TOKEN=токен_сообщества_VK
POLZA_API_KEY=ключ_Polza
POLZA_MODEL=идентификатор_модели_Polza
```

Затем проверь проект:

```powershell
python -m unittest discover -s tests -v
python -m app.main
```

Перед запуском VK-сообщество должно иметь включённые сообщения, возможности
ботов и LongPoll API с отслеживанием входящих сообщений.

## Команды и UX

Главное меню содержит кнопки `Написать пост`, `Продающий текст`, `Ответить
клиенту`, `Идеи контента` и `Ещё`. В дополнительном меню доступны
`Переписать текст`, `Профиль бренда` и `Помощь`.

Текстовые fallback-команды: `меню`, `назад`, `отмена`, `помощь`.

Профиль можно передать одной строкой:

```text
профиль: название | предложение | аудитория | тон | факты через запятую
```

Все примеры публикаций и brief считаются пользовательскими данными, а не
инструкциями для смены правил AI. Перед использованием результата нужно вручную
проверить факты. Кнопка `Подходит` не публикует и не отправляет текст.

## Безопасность

- реальные ключи хранятся только в `.env`;
- `.env`, `.venv`, SQLite и кэш Python исключены через `.gitignore`;
- ключ Polza не попадает в исключения и логи;
- trace хранит статус, провайдера, модель и latency, но не prompt/response;
- данные разделяются по `user_id`;
- не выполняются исходящие действия в VK кроме ответа пользователю.

## Ограничения учебной версии

Профиль сохраняется в SQLite при запуске через `app.main`, а краткое состояние
текущего диалога держится в памяти процесса. Импорт публикаций сообщества,
Kie.ai, платежи, квоты, админка, публикация и production deployment не входят
в MVP-0.

## Git и сдача

Локальный Git-репозиторий создаётся внутри `BotVK`. Перед добавлением файлов
проверь, что секреты не отслеживаются:

```powershell
git check-ignore -v .env .venv\ data\botvk.sqlite3
git status --short
```

Добавляй файлы поимённо. `.env` и `.venv` в публичный репозиторий попадать не
должны. Push в GitHub выполняется отдельно и только после проверки владельцем.
